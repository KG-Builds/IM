# Reports

- `FINAL_REPORT.md` — generated copy of the top-level final report.
- `../METHODS.md` — methodology.
- `../ALGORITHM_AUDIT.md` — notebook algorithm audit.
- `../PAPER_IMPLEMENTATION.md` — FIBMM paper-to-code mapping.
- `../aggregated/validation_report.md` — validation checks.
- `../aggregated/README.md` — table dictionary.
- `STATISTICAL_NOTES.md` — Monte Carlo vs optimizer variability.
- `ALGORITHM_BUDGETS.md` — selection budgets and fairness of comparison.
- `EXPECTED_RUNTIME.md` — observed per-component runtime estimates.
- `SAFETY.md` — workspace and safety compliance.
- `CHECKLIST.md` — deliverable checklist.

The final report is generated by `analyze_benchmark.py` from validated raw
results.  Regenerating it does not rerun any simulation.
