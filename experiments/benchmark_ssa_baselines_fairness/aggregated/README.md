# Aggregated tables

Generated by `analyze_benchmark.py` from `raw_results/results.csv` and the
per-run MC tables. No simulations are run here.

| File | Contents |
|---|---|
| `benchmark_results.csv` | Copy of the validated raw result table. |
| `winners_by_scenario_k.csv` | Winner, runner-up, margin, winner spreads, paired difference and 95% CI for each B × K cell. |
| `algorithm_summary.csv` | Mean/median/best/worst Net Advantage, win/tie/loss counts, mean rank, spreads and runtime per method. |
| `performance_by_scenario.csv` | Mean Net Advantage and spreads by method × opponent scenario. |
| `performance_by_k.csv` | Mean Net Advantage and spreads by method × K. |
| `ssa_vs_baselines.csv` | O1/O4/O6 vs every other method: wins/ties/losses and mean/median differences over the 20 cells. |
| `fibmm_fairness.csv` | FIBMM external Net Advantage/Blocked_B and internal Pi/tau/sigma, rank and CRP budget. |
| `fibmm_vs_ssa.csv` | FIBMM vs O1/O4/O6: Net Advantage wins/losses and mean Net Advantage/Blocked_B differences. |
| `runtime_summary.csv` | Selection, evaluation and preprocessing runtime plus optimization simulation counts. |
| `preprocessing_runtimes.csv` | One-time preprocessing runtimes (PageRank, NCGE centrality, communities, opponent orders). |
| `opponent_consistency.csv` | Proof that each scenario/K cell has one and only one B seed set across all methods. |
| `seed_set_validation.csv` | Per-cell A size, uniqueness and A/B disjointness checks. |
| `reuse_ledger_summary.csv` | Counts of completed, reused, invalidated and failed cells. |
| `validation_summary.json` | Machine-readable validation result, including the code fingerprint. |
| `code_fingerprint.json` | SHA-256 of the runner, analysis, algorithm and configuration files. |
| `validation_report.md` | Human-readable validation report. |
| `figure_manifest.csv` | Figure filenames and descriptions. |
